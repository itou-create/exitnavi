# 実地調査シート（1駅 約15分）

歩行空間ネットワークデータが未整備の駅で、案内に必要なデータを誰でも収集できるようにするためのシートです。
調査結果は `src/data/stations.ts` の該当フィールドにそのまま入ります（各項目に対応フィールドを明記）。

- 調査駅: ＿＿＿＿＿＿＿＿
- 調査日: ＿＿＿＿＿＿＿＿
- 調査者: ＿＿＿＿＿＿＿＿

## 1. ホームで記録すること（路線ごと）

| 項目 | 記録欄 | 対応フィールド |
|---|---|---|
| ホームの形式（島式 / 相対式） | | `platformType` |
| 両端の方面表記（現地の乗車位置案内の言葉で） | A端: ／ B端: | `platformEnds` |
| 階段の位置（A端を0、B端を1として 0〜1。複数あれば全部） | | `stairsPositionRatio` |
| 階段の段数（またはエスカレーター/EVの有無） | | `stairCount` |

**コツ**: 階段位置は「何両目の前か ÷ 編成両数」でおおよそ出せます（例: 4両編成で2両目の前 → 0.4）。

## 2. 改札で記録すること

| 項目 | 記録欄 | 対応フィールド |
|---|---|---|
| 改札の名前（現地表記） | | `gateName` |
| **改札を抜けた向きを基準に、各出口はどちらか**（直進/左/右/ななめ） | 出口＿＿: ／ 出口＿＿: | `gateToExitDirection` |
| 改札からの途中の案内板の表記 | | `signpostedAs` |

**ここが一番大事です。**改札を抜けて立ち止まり、体の向きを変えずに記録してください。

## 3. 出口で記録すること（出口ごと）

| 項目 | 記録欄 | 対応フィールド |
|---|---|---|
| 出口の名前・現地の看板表記 | | `name` / `signpostedAs` |
| 座標（Googleマップで出口地点を長押し→表示される数値） | | `position` |
| ホームからここまでの所要時間（ストップウォッチ。普通に歩いて） | | `traversalTime` |

## 4. 実走チェック

アプリの案内どおりに1回歩き、各ステップについて「合っていた / 逆だった / 表現が分かりにくい」をメモ。
アプリの案内画面の「実際と違っていたら報告する」ボタンからも報告できます（GitHub Issue が開きます）。

---

収集したシートは AI活用研究会の共有フォルダに置くか、そのままチャットに貼ってください。データへの反映は開発側で行います。
